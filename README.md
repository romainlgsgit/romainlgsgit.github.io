# Romain Legros — Portfolio

👉 **https://romainlgsgit.github.io**

Un portfolio en forme de voyage : on part de l'espace, on plonge vers la Terre, on descend sur Barcelone en imagerie satellite jusqu'au vrai Camp Nou, puis sur sa pelouse, pour découvrir mes projets autour du FC Barcelona.

- **BCN Social** — l'app des fans du Barça sur l'App Store
- **NewsTikitaka** — site d'actualité du Barça
- **pedri8lyn_** — site des edits Pedri

Fait avec HTML, CSS, JavaScript et Three.js.
Crédits : textures de la Terre NASA (via Three.js) · imagerie satellite © Esri, Maxar, Earthstar Geographics · photo du Camp Nou : Fish-guts (domaine public), Wikimedia Commons.
